# Password Generator

Генератор паролей на Python. Без зависимостей.

## Возможности

- 🔐 Генерация паролей любой длины
- 🔢 Несколько паролей за раз
- 💪 Оценка надёжности (слабый / средний / сильный)
- 💾 Сохранение в файл `passwords.txt`
- ⚙️ Опция отключить спецсимволы

## Запуск

```bash
python password_generator.py
